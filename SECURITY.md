# 安全问题 / Security

请通过公开仓库 Security 页的私密漏洞报告入口（Report a vulnerability）联系维护者。该入口应在公开前启用；若暂不可用，请勿在公开 Issue 中披露敏感细节。

请说明受影响版本、影响和使用合成数据的最小复现步骤。不要公开凭据、Cookie、Token、浏览器资料、数据库或未经脱敏的日志。

Please use the repository's Security → Report a vulnerability channel for private reports. Maintainers should enable it before publication. If it is unavailable, do not post sensitive details publicly. Include the affected version, impact and synthetic reproduction steps; never share credentials, session data, databases or unredacted logs.
